TradingJournalPro.co.uk

Our First Major Project

This project represents the culmination of our friendly competition and collaborative spirit. What started as a race between two aspiring developers became a comprehensive trading journal platform that showcases our full-stack development skills.

The result? A fully functional trading journal website that demonstrates our ability to work with modern technologies, implement secure authentication, and create an intuitive user experience for traders of all levels.

Next.js 14 React TypeScript Tailwind CSS NextAuth.js Prisma ORM PostgreSQL TradingView API Vercel bcrypt JWT

  • Responsive design across mobile and desktop
  • Real-time data visualization with TradingView integration

🚗 Lumara Auto — AI Car Triage

AI-Powered Automotive Diagnostics

Our latest innovation combines artificial intelligence with automotive expertise to create a comprehensive car diagnostic application. This project showcases our ability to build safety-first AI applications that provide real value to users while maintaining the highest standards of reliability.

Built with modern AI technologies and a conservative safety approach, Lumara Auto helps users describe car symptoms and receive step-by-step advice including severity assessment, likely causes, and mechanic-ready checklists. It represents our commitment to creating intelligent solutions that prioritize user safety above all else.
