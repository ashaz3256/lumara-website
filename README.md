# Lumara - Turning Insight to Innovation

A modern, professional website for Lumara, showcasing software engineering expertise and portfolio projects.

## 🚀 Features

- **Modern Design**: Clean, professional layout with smooth animations
- **Responsive**: Fully responsive design that works on all devices
- **Interactive Portfolio**: Filterable portfolio section with hover effects
- **Contact Form**: Functional contact form with validation
- **Smooth Scrolling**: Enhanced navigation experience
- **Mobile-First**: Optimized for mobile devices
- **Accessibility**: Built with accessibility best practices

## 📁 Project Structure

```
lumara-website/
├── index.html          # Main HTML file
├── styles.css          # CSS styles and animations
├── script.js           # JavaScript functionality
└── README.md           # This file
```

## 🛠️ Technologies Used

- **HTML5**: Semantic markup
- **CSS3**: Modern styling with Flexbox and Grid
- **JavaScript (ES6+)**: Interactive features and animations
- **Font Awesome**: Icons
- **Google Fonts**: Inter font family

## 🎨 Design Features

- **Color Scheme**: Professional blue and gold gradient theme
- **Typography**: Inter font for modern, clean look
- **Animations**: Smooth transitions and hover effects
- **Glass Morphism**: Modern glassmorphism effects
- **Floating Cards**: Animated hero section elements

## 📱 Responsive Breakpoints

- **Desktop**: 1200px and above
- **Tablet**: 768px - 1199px
- **Mobile**: Below 768px

## 🚀 Getting Started

1. Open `index.html` in your web browser
2. No build process required - pure HTML, CSS, and JavaScript
3. For development, use a local server (e.g., Live Server extension in VS Code)

## 🔧 Development Tips

### Performance Optimization
- Minify CSS and JavaScript for production
- Optimize images (WebP format, proper sizing)
- Implement lazy loading for images
- Use a CDN for external resources

### SEO Best Practices
- Add proper meta tags
- Implement structured data (JSON-LD)
- Create an XML sitemap
- Optimize page loading speed

### Accessibility
- Ensure proper color contrast ratios
- Add alt text for all images
- Implement keyboard navigation
- Use semantic HTML elements
